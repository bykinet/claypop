### 💡 이미지 권장 규격
- **포맷**: 고화질 **JPG**, **PNG**, **WebP** 포맷 모두 지원
- **권장 해상도**: `1920×1080px` (Full HD, 16:9 와이드 비율) 권장
- **인게임 반영**:
  - 홈 화면에서 선택한 타겟 테마에 따라 해당 게임 전용 배경이 3D 씬과 뷰포트 전체에 자동으로 펼쳐집니다.
  - 마이페이지나 홈 화면 배경 프리뷰에서도 테마별 배경을 실시간으로 확인하실 수 있습니다.
  - 이미지를 넣지 않은 상태에서는 기존의 스카이블루/그라디언트 3D 배경으로 안전하게 자동 폴백됩니다.
